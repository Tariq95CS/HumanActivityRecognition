# Human Activity Recognition (HAR)

Ce projet de Machine Learning vise à reconnaître automatiquement l'activité physique d'une personne (marche, position assise, debout, allongée, etc.) à partir de données collectées par des capteurs embarqués (accéléromètre et gyroscope).

## Fonctionnalités
- Chargement et exploration de datasets massifs de séries temporelles transformées (561 features).
- Encodage des étiquettes textuelles d'activités en variables catégorielles exploitables.
- Visualisation de la distribution des classes pour s'assurer de l'équilibre du dataset.
- Normalisation et standardisation des caractéristiques (`StandardScaler`) pour optimiser les performances des futurs modèles prédictifs.
